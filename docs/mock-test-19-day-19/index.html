Text 8: Die Verbraucherzentrale rät: Heben Sie Kassenbons mindestens zwei Jahre auf, denn so lange haben Sie gesetzliche Gewährleistung auf neue Produkte. Wenn ein Gerät innerhalb dieser Zeit kaputtgeht, können Sie Reparatur, Ersatz oder Rückgabe verlangen.

Text 9: Unser Geschäft schließt zum Jahresende. Alle Artikel sind bis zu siebzig Prozent reduziert. Gutscheine können noch bis zum einunddreißigsten Dezember eingelöst werden, danach verfallen sie.
