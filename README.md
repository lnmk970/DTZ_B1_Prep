# German Exam Prep

Mock exams for the German exams I am preparing for: **DTZ B1** (exam 10 Dec 2026) and **telc Deutsch B1** (exam 25 Feb 2027). A1 and A2 are placeholders for later.

**Live page:** https://lnmk970.github.io/German_Exam_Prep/ (GitHub Pages: branch `main`, folder `/docs`)

## Layout

```
docs/index.html              hub: progress, per-test results, links
docs/dtz/b1/…                DTZ B1 mock tests (generated by build.py)
docs/telc/b1/…               telc B1 Modelltests (generated by build_telc.py)
content/                     DTZ test content (Python)      content/telc/  telc test content (one JSON per Modelltest)
build.py  wcheck.py          DTZ generator and its checks   build_telc.py  telc generator (+ telc_lib.py, templates/telc_page.html)
gen_audio.py                 makes the .mp3 files from every audio.json (both exams)
```

DTZ and telc follow their **own official rules** (timings, points, pass criteria). They share only the look, the page flow and the autosave behaviour. Do not mix their scoring.

## Build

```
python build.py                 # DTZ pages
python build_telc.py            # telc pages  (python build_telc.py 8 = only Modelltest 8; --check = validate only)
python gen_audio.py docs        # mp3 for every audio.json (pip install edge-tts, ffmpeg on PATH; skips existing files)
```

## Add a new telc Modelltest

1. Copy `content/telc/mock-07.json` to `content/telc/mock-08.json` and edit it (set `"n": 8`).
2. Fill in: `theme`, `lesen` (Lesen 1–3, Sprachbausteine 1–2), `hoeren` (3 parts), `schreiben` (task, 4 Leitpunkte, `kw` = one regex per Leitpunkt, `rg` = `du` or `sie`, `len`), `sprechen` (3 parts; Teil 3 text needs `Besprechen Sie:` and points separated by ` · `), `model` (model letter, self-check, spoken model answers), `hoertexte` (listening scripts), `audio` (voice segments).
   Every item has `id`, `q`, answer options (`opts`, `letters` or `tf`), `key` and a `why` explanation.
3. `python build_telc.py --check` reports every mistake in plain words; then `python build_telc.py 8`.
4. `python gen_audio.py docs/telc/b1` creates `mock-test-08/hoeren.mp3`.
5. Commit and push. The telc list page and the hub pick the new test up automatically.

## Scoring (official rules, kept separate)

* **DTZ:** Hören 20 items, Lesen 25 items (≥33 of 45 = B1, ≥20 = A2); Schreiben max 20; Sprechen estimated /100 (/70 without the grammar check). B1 overall needs Sprechen B1 and (Hören+Lesen B1 or Schreiben B1).
* **telc B1:** schriftlich 225 points (Lesen 75, Sprachbausteine 30, Hören 75, Schreiben 45) and mündlich 75 points, 300 in total. Passed with ≥135 schriftlich **and** ≥45 mündlich.
  * Schreiben: 3 criteria (Aufgabenbewältigung, Kommunikative Gestaltung, Formale Richtigkeit), each A/B/C/D = 5/3/1/0, sum × 3 = max 45.
  * Sprechen: 4 criteria (Ausdrucksfähigkeit, Aufgabenbewältigung, Formale Richtigkeit, Aussprache und Intonation), each A–D. Teil 1 max 15 (4/4/4/3), Teil 2 and Teil 3 max 30 each (8/8/8/6).
  * The site estimates Schreiben and Sprechen automatically (keywords, length, LanguageTool grammar check, speech-recognition confidence) and fills the score fields. Typing your own score (or one from Claude) overrides the estimate. Estimates are rough and not official.

Progress is stored only in the browser (localStorage keys `dtz:N` and `telc:mt:N`). The hub can export and import it as a JSON file.
