# DTZ B1 Mock Exam Site: UI and Build Specification

Use this file to understand, change or recreate the site. It describes (1) how the HTML is produced, (2) the UI, (3) every feature and its exact behaviour, (4) the saved-state model, and (5) a ready-to-paste prompt.

---

## 1. How the HTML is created

The site is **static** (GitHub Pages, branch `main`, folder `/docs`). No server, no framework. Everything is generated by one Python script.

```
DTZ_B1_Prep/
  build.py            <- the generator (CSS + JS + HTML templates live inside it)
  explain.py          <- explanations: evidence quotes, gap rules, memory tips
  wcheck.py           <- Schreiben: register + keyword patterns per task
  gen_audio.py        <- makes hoeren.mp3 / sprechen_modell.mp3 (edge-tts + ffmpeg)
  content/
    mock_01_03.py ... mock_22_24.py   <- the questions and texts (24 mocks)
    extras.py         <- per mock: theme, Schreiben Aufgabe B, Sprechen Bild B
    l1cat.py          <- Lesen Aufgabe 1: real catalogue / directory
    lesen_long.py     <- longer Lesen texts (mocks 3-7)
  docs/               <- OUTPUT (what GitHub Pages serves)
    index.html, assets/{style.css,app.js,index.js}
    mock-test-NN-day-NN/{index.html, hoeren.mp3, sprechen_modell.mp3, bild-a.png, bild-b.png}
```

Build steps (`python build.py`):

1. `load_mocks()` reads the content files. `main()` merges extras (theme, Schreiben B, Sprechen Bild B), the Lesen 1 catalogue, and the long Lesen texts.
2. For every mock, `build_page(n, M, total)` returns one complete HTML page as a string:
   - `task()` makes one task card (title band, left text pane, right question pane, bottom nav).
   - `item()` makes one multiple-choice question (radio options).
   - `gap_sentence()` makes Lesen Aufgabe 5 (gap text).
   - `explain.py` creates the explanation data used later in review mode.
3. The answer key, explanations and task data are embedded in the page as a JSON object called `meta`.
4. The CSS and JS are written once to `docs/assets/` and linked with `?v=<BUILD>` (a timestamp) so browsers never use an old copy.
5. Audio: `python gen_audio.py docs` creates the mp3 files (skips existing ones). Images (`bild-a.png`, `bild-b.png`) were generated with an image model and saved next to each test.

Deploy: copy changed files to the repo, `git add -A`, `git commit`, `git push origin main`. Pages updates in 1-2 minutes. Browsers may need Ctrl+F5.

Only mocks 1-7 are linked from the home page and use the new UI. Mocks 8-24 still use the old UI (`docs/assets-old`).

## 2. UI layout

Style: dark navy (`#0d1b2e`), gold (`#f6c25b`), teal (`#0b7a75`). Fonts: Manrope (UI) and Newsreader (reading texts).

### Home page (`docs/index.html`)
- Hero: badge "DTZ B1", "7 Modelltests", exam date and days left, four score tiles (Hören, Lesen, Schreiben, Sprechen).
- Progress bar and rule text (pass rule: Sprechen B1 and Hören/Lesen 33/45 or Schreiben).
- List of mock tests with status (offen / in Arbeit / abgeschlossen) and results.
- Phones: tiles in two columns, rows wrap.

### Exam page (`docs/mock-test-NN-…/index.html`)
1. **Start screen** (split): left = big mock number; right = flow list, rules, **Prüfung starten**, **Zurücksetzen**.
2. **Header (sticky):** home icon (left), logo, big timer (sum of remaining written time) with a sub-timer below, yellow **"<Teil> beenden"** button, **Prüfung beenden**.
3. **Left menu:** Hören, Lesen, Schreiben, Sprechen, Antworten (horizontal strip on phones).
4. **Main area:** one section at a time. Each task card = title band + two panes (left text, right questions) + bottom bar (Zurück, Speichern, Weiter).
5. **Right palette:** question numbers grouped by Aufgabe. Green = answered, orange = visited but blank, grey = not seen. Click to jump.
6. Modal dialogs and a small toast for messages.

## 3. Features and exact behaviour

### Exam flow
- Nothing runs until **Prüfung starten** is clicked.
- **Hören first.** Lesen, Schreiben and Sprechen are locked until Hören ends.
- Fresh start: 30 s reading countdown, then the audio plays automatically **once**. Only the Hören timer (25 min) is shown. No pause, no replay.
- After Hören: Lesen or Schreiben in any order. Each has its own start gate ("Lesen starten" / "Schreiben starten"). Budgets: Lesen 45 min, Schreiben 30 min (active time only).
- Header timer = remaining written time (25 + 45 + 30 = 100 min total); sub-timer = current section.
- Time running out locks that section automatically.
- Hören tab is locked after it ends. Sprechen unlocks after the written parts.
- Yellow button in the header ends only the current section (with a confirm). **Prüfung beenden** opens a dialog listing only sections that are still open; ended sections are not asked again.

### Pause and home
- Home icon asks: "Sie sind mitten in der Prüfung … pausieren?" Yes = timer stops, state saved, go to home. Opening the test again resumes the same section, timers and (during Hören) the audio position.
- Closing the tab does **not** pause the timer (like a real exam).

### Reset
- **Zurücksetzen** on the start screen clears all answers, timers and recordings of that test so you can practise again. (Also cleared when you choose "Neu beginnen".)

### Reading layout (Lesen)
- Left pane = text (fixed), right pane = questions (scrolls), on desktop.
- **Aufgabe 3 (three texts):** each text is pinned at the top while its own questions scroll. When that text's questions are finished the text scrolls away and the next text pins (CSS `position: sticky` inside one wrapper per text; long texts are capped at ~42% of the screen and scroll inside their box).
- Phones: left text pane becomes sticky under the header (max ~35% of the screen).
- Aufgabe 1 shows a real catalogue (table) next to five situations. Aufgabe 5 is a gap text with 3-option gaps.

### Schreiben
- Choose Aufgabe A or B (A: halbformell/informell, B: formell). Word counter, save button, **Für Claude kopieren** (copies test name, chosen Aufgabe, situation, 4 required points, the letter and instructions for marking).

### Sprechen
- Four recorder rows (Teil 1, Teil 2 Bild A, Teil 2 Bild B, Teil 3), each with a timer.
- Record with the microphone (MediaRecorder), live transcript with the browser speech recogniser (`de-DE`, Chrome/Edge), editable text, playback. Audio is stored in IndexedDB (`dtz-audio`), text in localStorage.
- **Für Claude kopieren** copies all tasks, transcripts, durations and notes.

### Review (Antworten) after submitting
- All sections open read-only. Hören has a normal audio player (play, pause, seek).
- Under each question: correct option green, wrong choice red, and an explanation box: status, your answer, correct answer, "Warum richtig?" (quote from the text), "So findest du die Antwort", "Merksatz".
- Schreiben: automatic estimate out of 20 (Inhalt 5, Gestaltung 5, Wortschatz + Grammatik 10) with a checklist, error list from the LanguageTool API, model letter, copy button.
- Sprechen: estimate out of 85 (Inhalt 35, Wortschatz 15, Redefluss 10, Grammatik 25), per-part checklist, model answers and model audio, copy button. Pronunciation is not rated.
- The scores are estimates only, not official.
- The page tells Chrome **not to translate** during the exam (`translate="no"` + meta tag). On submit the page reloads once without it, so you can translate while reviewing.

### Scoring rules in the code
- Hören 20 items, Lesen 25 items = 45 points. 33+ = B1, 20+ = A2 (shown on the Antworten page).

## 4. Saved state (localStorage key `dtz:N`)

| Key | Meaning |
|---|---|
| `sel` | selected answers `{ "h1": 0, ... }` |
| `vis` | visited questions (for the orange palette colour) |
| `el` | elapsed active seconds per section |
| `act`, `since` | currently running section and its start time |
| `lock` | sections that have ended |
| `began`, `t0` | start gates and exam start time |
| `cur`, `where` | current section/task |
| `paused`, `pact`, `preLeft`, `apos`, `aend` | pause/resume data (incl. Hören countdown and audio position) |
| `fin` | exam submitted (review mode) |
| `wt`, `brief` | Schreiben choice (A/B) and letter text |
| `sprech`, `rc` | Sprechen notes and recordings `{part:{sec,txt,aud}}` |
| `lt`, `lt2` | cached grammar-check results |

Active-time rule: `elapsed(section) = el[section] + (act === section ? now - since : 0)`.

## 5. Prompt to recreate or extend the site

> Build a static DTZ B1 (Deutsch-Test für Zuwanderer) mock-exam website for GitHub Pages (`/docs`). A Python script `build.py` generates one self-contained HTML page per mock test plus shared `assets/style.css`, `app.js`, `index.js` (cache-busted with `?v=<timestamp>`). Content (questions, texts, answer key, explanations) lives in Python modules; each page embeds a `meta` JSON.
> Exam: Hören (20 items, 25 min, audio plays once, starts after a 30 s reading countdown), Lesen (25 items, 45 min), Schreiben (30 min, task A or B), Sprechen (3 parts). Nothing starts until "Prüfung starten". Hören first and locks the other sections; then Lesen/Schreiben in any order, each with its own start gate and an active-time budget; Sprechen last. Header shows the total remaining written time plus a section sub-timer; Hören shows only its own timer. Time-out locks a section. A header button ends the current section; a finish dialog lists only open sections.
> Home icon (left of the header) asks to pause; the exam resumes at the same section, timers and audio position. A per-test reset clears everything.
> Layout: sticky dark header, left section menu (strip on phones), two-pane task cards (text left, questions right), right palette (green answered, orange visited-blank, grey unseen). In Lesen the text stays fixed while questions scroll; with several texts each text is sticky until its questions end, then the next one takes over. Mobile-first fixes: no horizontal scroll, compact header, sticky text under the header.
> Schreiben: A/B choice, word count, copy-for-Claude button. Sprechen: per-part recording with live German transcript, playback, copy-for-Claude button.
> After submitting: read-only review of all sections, Hören audio player, correct/wrong colouring, an explanation box under every question (why right, how to find it, memory tip), automatic estimates for Schreiben (/20) and Sprechen (/85) using keyword checks and LanguageTool, translation allowed only in review. Save all state in localStorage (audio in IndexedDB). No next-exam links.
> Style: navy/gold/teal, Manrope + Newsreader, premium full-width look.
